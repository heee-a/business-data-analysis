M5Apriori 关联规则support ≥ 0.01（有铺货价值）/ lift > 1.0（正向关联）/ conf ≥ 0.15（推荐可命中）fig30 · fig31

一键复现

随机种子在 scripts/utils/config.py 中固定为 2026，任何人克隆后均可得到完全一致的结果。

# 1. 克隆仓库
git clone https://github.com/heee-a/business-data-analysis.git
cd business-data-analysis

# 2. 安装依赖（建议 Python 3.11+ 虚拟环境）
pip install -r requirements.txt

# 3. 一键复现全部结果（10 个阶段，约 8 分钟）
python run_all.py

# 常用参数：--list 查看阶段 | --only 4 5 仅出图 | --skip 1 2 跳过取数与清洗
