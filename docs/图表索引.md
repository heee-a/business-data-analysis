## 三、大屏交互能力说明

| 能力 | 实现方式 | 涉及组件 |
|---|---|---|
| 筛选 | 图例点击开关数据系列 | tab1/tab2/tab3 全部图形组件 |
| 缩放 | dataZoom 滑块 + 时间轴轮播 | tab1_trend、tab1_timeline、tab4_forecast |
| 联动 | Timeline 驱动月度国家排名演进 | tab1_timeline |
| 下钻 | 明细表可排序、悬停显示明细 | tab3_table、tab2_cohort |
| 悬停 | 全组件 tooltip 显示精确数值 | 全部 |
